# «После финала: мир‑2026»

Авторский пример многораундовой игры QuizRoom: 7 туров, 39 вопросов, 23 вопроса с иллюстрациями/схемами, три типа ответа, 48 базовых баллов. При всех верных ответах и максимальных ставках — 66 баллов. Игра рассчитана на 60–80 минут с обсуждением и разбором.

Туры: «Первый свисток», «Смотри в оба», «Досье на героев», «На табло — риск», «Шесть точек на карте», «Три задачи штаба», «Последние шесть». В шестом туре три задачи по два балла, в финале шесть вопросов по два балла со ставками. Все начисления и проверка ответов автоматические.

Ключ каталога: `after-final-world-2026`. Запуск: `room-test.html?quiz=after-final-world-2026`. Документ доступен администраторам в обычном конструкторе под названием игры. Цена — 0; платежи не включены.

Визуальный стиль: ночь на стадионе, электрический синий, лайм и золото; собственная редакционная графика. Обложка `wc26-cover.jpg` показывается в каталоге, лобби и перед первым туром. Ещё три JPG — оригинальные иллюстрации, созданные встроенным imagegen. Это художественные образы, не фотографии матчей. Семь SVG — точные схемы условий, табло и диаграммы; часть содержит ненавязчивую анимацию. У иллюстраций есть текстовые описания; вопросы доступны без распознавания изображения. Вопросы появляются плавно, с учётом системного уменьшения движения.

Факты сверены 20 октября 2026 года по материалам FIFA и репортажам AP. Источник указан в пояснении каждого ответа; расчётные задачи отделены от исторических фактов. Не используются вопросы или оформление сторонних коммерческих квизов.

Полный JSON для импорта, ключи, журнал проверки фактов и SQL публикации хранятся в локальной папке `private-content/wc2026`, исключённой из Git. Они не публикуются в открытом репозитории: игрок получает правильные ответы только на этапе разбора. Публикация нового документа выполняется административной транзакцией с существующим валидатором; права доступа и функции авторизации не меняются.

Проверки: клиентский импорт/валидация, три полных локальных прогона (верно/неверно/пусто), полный серверный прогон 39 вопросов для двух игроков (+66/−18), сохранение итогов, защита будущих вопросов и правильных ответов. Серверные тестовые комнаты откатываются транзакцией.
