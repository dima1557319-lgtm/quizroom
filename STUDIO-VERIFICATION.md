# Проверка конструктора

15 октября 2026: миграция применена в Supabase. В транзакции с откатом проверены закрытые черновики, конфликт версий, запрет публичного custom, запрет запуска платного квиза, четыре типа ответов, баллы 0,5 / 1 / 1,5, три режима начисления/раскрытия, ручная оценка и повторная отправка. Результат PASS. Сохранены 30 квизов каталога.

Локальная форма проверена с изолированным тестовым клиентом: цена с запятой, дробные баллы, выбор нескольких правильных вариантов, сохранение и предпросмотр. Тестовый клиент не публикуется и не подключён к базе.

Вход владельца не выполнялся: свой пароль он создаёт самостоятельно на admin.html и подтверждает email. Приём оплаты не подключён; платный запуск закрыт сервером для посетителей.

После установки повторно проверен доступ по разрешённому подтверждённому email и отказ для неподтверждённого email — PASS. В браузере с настоящим Supabase проверены создание комнаты, QR, вход игрока, realtime 1 / 20, старт, отправка ответа, начисление 1 балла и завершение игры. GitHub Pages открывает закрытый вход администратора.
